# 💻 Code Snippet Generator

A web application built with **Streamlit** and **Google Gemini API** (`gemini-3.6-flash`) that generates clean, efficient, and well-commented code snippets from natural language descriptions.

---

## 🚀 Features

- **Multi-Language Support**: Supports Python, JavaScript, TypeScript, C++, Java, SQL, Go, Rust, HTML/CSS, and PHP.
- **Fast Generation**: Powered by Google's `gemini-3.6-flash` model for instant responses.
- **Clean UI**: Built with Streamlit for a smooth and simple user experience.

---

## 🛠️ Tech Stack

- **Framework**: Streamlit
- **AI Model**: Google Gemini API (`google-genai`)
- **Language**: Python 3.x
